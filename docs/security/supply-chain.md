Current review: 2026-10-29. Older reconciliation counts describe historical lockfiles and are superseded by the dated scan evidence, dependency/IP ledger and current SBOM.

| Check                  | Current evidence                                                                                    | Limit                                                                                                 |
| ---------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Clean installation     | Exact-head CI uses npm ci; the SDK and framework example are installed as consumers                 | A passing install is not artifact provenance                                                          |
| Root advisory audit    | npm audit reported zero advisories after pinning stripe 23.0.1                                      | Point-in-time registry advisory result, not absence of vulnerabilities                                |
| Example advisory audit | Separate golden-path lock audit reported zero advisories                                            | Example dependencies are inventoried separately                                                       |
| Root licenses          | 666 locked components with known manifest license fields                                            | Does not inspect every distributed file or provide a legal opinion                                    |
| Example licenses       | 77 locked entries with known fields in examples/golden-path/DEPENDENCIES.json                       | Includes optional uninstalled binaries and the local SDK target                                       |
| SBOM                   | CycloneDX 1.5, 666 root-lock components and 667 root/component dependency nodes                     | Peer edges omitted; no deployed-binary attestation; unavailable IRI/email format validators disclosed |
| Secret scanning        | Pinned/checksummed Gitleaks source/history CI; exact passing runs in the ledger                     | A scan result is not proof that secrets can never be exposed                                          |
| Ownership and assets   | Apache-2.0 source/SDK, original Boundary vectors, font notices, restricted attributed Commons media | Qloo data/marks and vendor services retain separate rights                                            |

The root SBOM is generated by scripts/update-sbom.mjs from the root lock and license ledger. It includes development and optional uninstalled packages, available integrity strings, and resolved dependency/optional-dependency edges. It replaces the older production-only 146-component artifact. The generator identifies itself accurately; the failed npm sbom attempt is not described as successful.

MPL-2.0 tooling and LGPL native image-processing binaries have file/linking/redistribution obligations. They are not modified by this build; preserve notices and review the actual distribution before shipping binaries. Manifest expressions alone do not resolve every obligation or eliminate supply-chain risk. The public SDK declares jose separately and excludes repository caches, tests, secrets and build tools from its tarball.

No external penetration test, reproducible-build attestation, legal license audit, SOC 2 or ISO certification has been obtained. Security fixes and new dependencies require their own exact-head checks. See scanning-2026-10-29.md, threat-model.md, operations.md and the company-build ledger for actual tested revisions.
