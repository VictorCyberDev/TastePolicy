# TasteBench v1 contracts

Runtime TypeScript definitions: ../../lib/types.ts. Authoritative fail-closed validators: ../../lib/validate.ts and run.ts. These are application schemas; no extra JSON Schema engine is installed. Unknown keys, malformed IDs, nonfinite scores, wrong ownership/version linkage and stale hashes fail validation.

| Record            | Version and required content                                                                                                                                                                                                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scenario          | tastebench-scenario-v1; unique ID, CALIBRATION/EVALUATION split, ENGINEERING/HUMAN kind, SYNTHETIC/CAPTURED source; input; optional registered feedback/clarification/repair; perturbations; independent contract expectations; contentHash.                                                                                                                                                |
| Input             | Five distinct reviewed normalized entities across domains; separate supported candidate; explicit context; immutable state hash/version; typed captured cultural result; evaluation timestamp. No arbitrary extra metadata.                                                                                                                                                                 |
| Annotation        | tastebench-annotation-v1; annotation version, scenario ID, declared HUMAN source, pseudonymous annotator, ALLOW/ASK/REJECT/UNSCORABLE, bounded reason categories/comment, timestamp. Synthetic cases cannot receive human records.                                                                                                                                                          |
| Adjudication      | Scenario ID, declared HUMAN_ADJUDICATION, pseudonymous reviewer, label, every underlying annotation hash, timestamp after annotations. No automatic voting.                                                                                                                                                                                                                                 |
| Dataset manifest  | tastebench-manifest-v1; dataset version/hash, annotation version/hash, metric version, count by split/domain/source, sorted ID/content/record hashes, creation timestamp and provenance.                                                                                                                                                                                                    |
| Prediction        | tastebench-prediction-v1; scenario/system/version, exact candidate, system-input hash; OK or INVALID_OUTPUT; decision or null; basis/reason, CAPTURED mode, data source, latency kind/ms, provider count, provenance, actual receipt or null, semantic hash.                                                                                                                                |
| External response | tastebench-external-v1; scenario/system/candidate/input hash, response, declared provider/model/version, prompt version, execution time, temperature/seed or null, response hash, latency/count. Response must be exactly structured decision/reason; malformed response is INVALID_OUTPUT, not guessed. An unparseable JSONL envelope fails import because it cannot safely be attributed. |
| Run manifest      | tastebench-run-v1; run/time/code SHA/dirty state/Node version; full dataset manifest; executed systems and versions; prompt/metric versions; evidence mode; environment blocks; counts; exclusions; seed; raw artifact and semantic hashes.                                                                                                                                                 |

Human records in automated tests are validator fixtures only. Schema validation is not proof of a person's identity, consent, truthfulness, provider origin or cryptographic authenticity. Private operator provenance review is required before publication.
