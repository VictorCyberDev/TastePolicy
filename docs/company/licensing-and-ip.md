# Licensing, ownership and company boundary

Reviewed 2026-10-29. This records source evidence and unresolved diligence, not a legal opinion, trademark clearance or IP valuation.

The repository and proposed SDK carry Apache-2.0. Already published grants remain in place. No exclusive ownership over Qloo's cultural graph, MCP, A2A, cryptographic standards, third-party libraries or user preferences is claimed. Future proprietary work must start with a clearly separated ownership/license boundary; changing a future license does not revoke earlier Apache grants.

## Open and commercial layers

Keep public: protocol contracts, verifier, conformance vectors, SDK, examples, benchmark methodology and source currently released under Apache-2.0. Open interfaces support independently verifiable authority boundaries. Hosted operations, integrations, tenancy, support and a commercially licensed provider service can create recurring value. These are commercial services, not evidence of exclusive IP. User state remains exportable and deletable.

Future hosted-only components may include billing administration and operational dashboards. No present file is retroactively declared proprietary. A source-available edition would require an explicit new license and contributor/ownership review before publication. The current release has one public Apache edition.

## Dependency and asset record

`dependency-ip-ledger.json` enumerates 666 root-lock packages, versions and license expressions, including development and optional platform binaries. No missing license expression was found in that generated inventory. It is a package-manifest audit, not proof that every distributed file has been inspected. MPL-2.0 build dependencies and LGPL libvips/native binaries require preservation of notices and review of redistribution/linking obligations. Combined Apache/LGPL expressions do not erase the LGPL obligations. Public SDK `jose` dependency is separately included in its package manifest.

Original Boundary SVG artwork lives in `public/brand`; raster exports derive from those files. The bundled font license notices remain with the repository assets. No third-party logo implies a partnership. Qloo's marks and cultural data retain their owners' rights. Written API commercialization, output redistribution, retention and attribution rights remain pending the commercial inquiry documented in `qloo-commercial-and-data.md`.

Wikimedia image lookup in `src/app/api/media/place/route.ts` accepts a limited set of CC BY, CC BY-SA, CC0 and public-domain metadata only when the canonical license URL matches. It requires creator and file-page attribution, restricts image hosts and labels the result LOCATION_CONTEXT, with exact property identity unverified. The presentation component must retain creator/license/source links. Do not place those images into reusable company artwork or imply that all Commons media has a single license.

## Contributor policy

Contributors retain copyright and submit Apache-2.0 contributions under the repository license. Require truthful authorship and a Developer Certificate of Origin sign-off for new outside contributions. No CLA or transfer of all contributor IP is currently collected. A maintainer should reject code/assets without a traceable license or with private customer/provider data. Generated contributions still require dependency, provenance, security and substantive human review. Never submit secrets or private pilot responses.

## Name and trademark checklist

TastePolicy is a working product name. No registered trademark, incorporated entity or custom-domain ownership is claimed. Before spending on filing or international launch, search USPTO, WIPO and relevant local registries for exact/phonetic names and related goods; inspect existing product/package names, app directories and domain registrations; record jurisdictions/classes and obtain counsel's review. A web search or free npm name does not establish clearance. Proposed npm scope `@victorcyberdev` is unverified until authenticated registry ownership is proven. The canonical temporary Vercel hostname is not ownership of tastepolicy.com or tastepolicy.dev.

## Defensibility thesis

Potential defensibility comes from reliable authority semantics, portable proofs with independently checked commitments, integration quality, legitimate consented evaluation data and operational trust. The current ten-person descriptive pilot does not establish a performance moat. Qloo supplies a licensed substrate that competitors may also access. No patent, trade-secret protection, exclusive agreement or competitive advantage is asserted as obtained.
