# 90-second judge script — rehearsal, not measured acceptance

PRE-RECORDING: live Qloo and hosted persistence must pass WG-A. If not, show unavailable honestly and identify any historical evidence. No current live success is claimed by this script.

0–15s: Open /arena. “An agent can know your taste and still make a choice it is not justified in making. Qloo gives agents taste. TastePolicy gives that taste authority boundaries.”

15–35s [LIVE REQUIRED]: resolve and explicitly review the five cultural identities; discover a place, select one and evaluate. Show actual outcome, not a promised ALLOW. For a previously verified strong candidate, an ALLOW permits recommendation/draft only, never booking/payment. Do not cherry-pick or edit scores to force it.

35–55s [PERSISTENCE REQUIRED]: save the reviewed signals explicitly. Keep the candidate. Add a USD 100 dinner constraint; leave price unknown and evaluate. Show the actual ASK/missing factor where supported. Or explicitly exclude the candidate and evaluate REJECT; a high cultural affinity does not erase the rule.

55–70s [PERSISTENCE REQUIRED]: use the accepted clarification flow, supply an explicit answer, inspect the new interaction decision. For REJECT show bounded repair only when a verified different candidate exists. Never claim a failed/unsupported repair worked.

70–80s: inspect Qloo identity/affinity/provenance versus TastePolicy state/context/policy/receipt. Show unavailable rehearsal only with DEMO FAULT INJECTION label; it is not a Qloo outage or a replacement decision.

80–90s [SEPARATE PROCESS]: show the external trace AGENT PROPOSED → TASTEPOLICY DECIDED → AGENT OBEYED, labeled live/captured/synthetic accurately. End: “Knowing someone is not permission to act on everything you know about them.”

A fresh human must verify <20s comprehension and <90s core proof. Timing is not established by this script or automated tests. If setup cannot fit, record separate setup and do not pretend the judge completed it in 90 seconds.
